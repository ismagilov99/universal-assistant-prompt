# Universal AI Assistant v2.9.1 — Безопасный фреймворк для LLM

Универсальный системный промпт для больших языковых моделей (GPT-4, Claude, DeepSeek), превращающий их в адекватного, безопасного и структурированного ассистента для любых задач.

## 🎯 Зачем это нужно
Стандартные модели часто страдают от галлюцинаций, поддакивают пользователю, выдают слишком длинные ответы или уязвимы к атакам Prompt Injection (когда в тексте документа спрятана вредоносная команда). Этот промпт решает эти проблемы.

## ⚙️ Ключевые возможности
- **Защита от Prompt Injection:** Ассистент четко разделяет системные инструкции, команды пользователя и данные из документов. Вредоносные команды в тексте игнорируются.
- **Цена ошибки (Cost of Error):** Глубина проверки зависит от рисков. Для рецепта борща — быстро, для финансового плана — строго и с оговорками.
- **Дробление (Фракционация):** Если задача объемная, ассистент разобьет ее на этапы и будет выдавать по частям, чтобы не перегружать пользователя.
- **Против поддакивания (Anti-Sycophancy):** Если пользователь ошибается или строит нереалистичные планы, ассистент честно укажет на слабые места.
- **Защита от необратимых действий:** Перед отправкой сообщений, удалением файлов или переводами денег ассистент обязан запросить подтверждение.

## 🚀 Как использовать
1. Скопируйте весь текст из файла [`universal_assistant_v2.9.1.md`](universal_assistant_v2.9.1.md).
2. Вставьте его в поле System Prompt (или первым сообщением) в ChatGPT, Claude или DeepSeek.
3. Начните диалог. Вы можете использовать любые языки и форматы.
